# JPI Flow / ExamVue 365 Flow

## 로그인 3D 첫 구현 — 검토 브랜치

`feature/login-3d-preview`에는 Figma 로그인 화면과 **261101.blend 원본 메시·카메라를 사용하는 실시간 3D 스튜디오**의 `/login/` 미리보기가 있습니다. 파란 구와 원형 구멍이 있는 유리판 6개 배열을 기본으로 제공하며, 오른쪽 패널에서 형상·재질·초점·전체 이동을 편집합니다. 이전 곡선·타일 모델은 비교 프리셋으로 보존합니다. `node tools/serve-login.mjs` 실행 후 http://127.0.0.1:4173/login/?controls=1 에서 확인하세요. 실행·설정·Blender 재추출·GitHub·배포 방법은 [로그인 README](dist/login/README.md)를 참고하세요. **공개 배포와 main 병합은 수행하지 않습니다.**

ExamVue 365 Flow 소개 웹사이트의 현재 작업 코드입니다.

공개 사이트: https://jpiflow.ffe400.chatgpt.site

## 프로젝트 구성

- `dist/`: HTML, CSS, JavaScript, 이미지, 폰트, Three.js 등 사이트 파일
- `tools/local-server.ps1`: Windows 로컬 미리보기 서버
- `start-local-server.bat`: Windows 미리보기 실행
- `.openai/hosting.json`: 기존 Sites 배포 대상 설정 (인증 정보 없음)

별도 빌드 과정 없이 `dist/`를 웹 서버에서 제공합니다. HTML 파일을 직접 열면 모듈·이미지 경로가 제대로 작동하지 않을 수 있습니다.

## 다른 컴퓨터에서 작업

1. 이 저장소를 clone하고 Codex에서 폴더를 엽니다.
2. Windows에서는 `start-local-server.bat`를 실행합니다. 기본 주소는 http://localhost:8080 입니다.
3. `dist/`의 파일을 수정합니다.
4. 작업을 마친 뒤 commit/push하고, 다른 컴퓨터에서는 작업 전에 pull합니다.

동시에 두 컴퓨터에서 같은 파일을 수정하기보다는 한 컴퓨터에서 push한 다음 다른 컴퓨터에서 pull하는 방식을 권장합니다.

## 공개 사이트 배포

이 저장소에 push하는 것만으로 현재 Sites 사이트가 자동 배포되지는 않습니다.
Codex에서 기존 Sites 연결을 사용해 `.openai/hosting.json`의 프로젝트 ID를 유지하고, 현재 `dist/`를 패키징해 배포합니다. 새 사이트를 생성하지 마세요.
다른 컴퓨터에서 필요한 로그인·연결은 해당 계정으로 다시 진행합니다.

## 작업 안내

이 저장소는 기존 로컬 원본의 현재 스냅샷입니다. 과거 Git 기록, 배포 압축본, 검토 스크린샷, 로그인 토큰은 포함하지 않습니다.
기존 디자인, 문구, 이미지, 리본 설정, 등장 애니메이션 및 모바일 최적화를 유지하면서 필요한 부분만 수정하세요.

Three.js 및 Pretendard 등 포함된 외부 라이브러리·폰트의 라이선스는 해당 파일과 함께 보존합니다.

## 로그인 3D 시안 · 파란 중심과 속이 빈 유리 반구

`feature/login-3d-preview` 브랜치에서 작업합니다. Node.js 설치 후 다음 명령으로 실행합니다.

```sh
node tools/serve-login.mjs 4174
```

- 로그인 화면: http://127.0.0.1:4174/login/
- 장면만 보기: http://127.0.0.1:4174/login/?view=scene
- 우측의 **3D 설정**에서 전체 이동, 중심 형태, 속이 빈 유리 반구, 재질과 모션을 편집합니다.

Pinterest 633881716349791611의 중심 오브젝트와 문구를 참고한 시안입니다. 모니터, 화면 테두리, 물리적 받침대와 배경 건축물은 구현 대상에서 제외했습니다. 중앙과 바깥 유리 반구 모두 열린 입구가 있는 속이 빈 실제 3D 껍질입니다. 문구는 선택 가능한 HTML 텍스트입니다. 문구는 의미 단위로 등장하고 파란 반구와 유리 반구들은 각각 회전·부유합니다. 움직임 줄이기를 지원합니다. 기존 로그인 폼과 이전 모델들은 유지합니다.

설정 구조는 `dist/login/studio-state.js`에 정의되어 있습니다. 새 모델 이름은 `pinOrbit`, 중심은 `pinCore`, 유리 반구 전체는 `pinRings`이며 각 그룹의 위치·회전·크기, `material`, `motion`은 독립적입니다. 형상은 `pin-orbits.js`, 렌더링은 `scene-v2.js`, 문구는 `studio.js`와 `studio.css`에서 관리합니다. 중앙 반구도 바깥 유리와 같은 방식의 빈 껍질로 구현합니다. 중앙의 가로·높이·깊이와 실제 벽 두께, 입구 테두리 둥글기를 독립적으로 조절할 수 있으며, 입구를 막는 원판이 없습니다. 바깥 유리는 열린 입구·외부 곡면·내부의 오목한 곡면·둥근 입구 테두리를 가진 실제 얇은 반구형 벽입니다. 입구를 가로막는 원판은 없습니다. 파란 반구와 유리 반구는 구의 중심을 맞춰 배치하며, 유리 반구별 기울기와 자체 회전 속도를 따로 조절합니다. **유리 반구 전체 → 형태·배열 → 유리 반구 보기 → 속이 빈 형태 확인**으로 재질 영향을 제외하고 형상을 확인할 수 있습니다. 가로·높이·깊이, 절단면 테두리 라운드, X·Y·Z 기울기를 조절할 수 있습니다. 기존 큐브 설정은 카메라·재질·궤도·모션을 유지한 채 중심 형태와 반구 비율·기울기만 한 번 보정합니다. 보정 전 설정은 브라우저의 `examvue.studio.v2.beforeHemisphere`에 보존합니다. 형태 변경 시에만 메시를 재생성하고 이전 지오메트리를 해제합니다. 회전 속도는 시간에 따라 적분해 변경 시 각도가 튀지 않게 합니다.

현재 기준값은 사용자가 붙여넣은 JSON입니다. 원본을 `dist/login/presets/selected-20261117.json`과 브라우저용 `.js`로 보존했고, **저장 → 선택한 설정 · 2026-11-17**에서 복원합니다. 위치·회전·카메라·각 반구의 재질과 모션은 원본 값을 유지하며, 중앙의 빈 껍질용 벽 두께·테두리 항목만 추가했습니다. 첫 적용 전 브라우저 설정은 `examvue.studio.v2.beforeSelected20261117`에 백업합니다. 이후 편집은 자동 저장되며 기준 프리셋이 매번 덮어쓰지 않습니다.

투명체는 `hemisphere-composite.js`에서 실제 화면 깊이를 여러 층으로 구한 뒤 먼 표면부터 PBR로 합성합니다. 중앙 반구도 같은 합성에 포함하므로 불투명도가 1에서 0.99로 바뀔 때 렌더 큐나 앞뒤 순서가 전환되지 않습니다. 깊이 마스크는 단일 샘플로 계산하고 완성된 이미지에 FXAA를 적용해 경계의 샘플 불일치와 구멍을 피합니다. 기본 반구 4개는 최대 8개의 표면 층을 처리하므로 기본 렌더보다 비용이 높습니다. 형상 탭의 **투명 반구 합성 → 기본 렌더**는 가벼운 비교용이며, 겹치는 투명 표면의 정확한 앞뒤는 **표면 깊이 합성**을 사용합니다. 불투명도는 반사까지 함께 희미하게 만들고, 유리 투과율은 표면 반사를 유지하며 빛을 통과시킵니다.

개별 재질은 **3D 설정 → 조절 대상 → 유리 반구 1 / 2 / 3 → 색상·재질**에서 편집합니다. 반구마다 별도의 `MeshPhysicalMaterial`을 사용하며 `pinRings.layers.one/two/three/four.material`에 저장합니다. 파란 반구는 `pinCore.material`입니다. 4개로 늘리면 4번 반구 선택도 나타납니다. 기존 공유 재질 설정은 각 반구에 복제해 보존합니다. 재질 변경 시 지오메트리를 재생성하지 않습니다.

기본은 선택한 반구에만 적용됩니다. **유리 반구 전체**는 변경한 속성만 유리 반구들에 일괄 적용하는 기준값입니다. **재질 복사 · 연결**을 펼치면 유리 반구들에만 전체 재질 복사, 파란 반구까지 전체 복사, 이후 변경 속성 연결을 각각 사용할 수 있습니다. 개별 재질 탭의 **선택 반구 재질 초기화**는 해당 재질만 초기화합니다. 다른 반구의 형태·재질·카메라·모션은 보존합니다.

설정은 브라우저에 자동 저장됩니다. 저장 탭의 **기억한 현재 설정 · 유리판과 파란 구**는 이전에 요청한 기준값을 복원합니다. 원본은 `dist/login/presets/current-baseline.json`이며, 구 이동 깊이 1.2u와 반복 시간 4.4초를 포함합니다. 이번 구성 수정 직전에 내보낸 설정은 `dist/login/presets/before-content-revision.json`으로도 보존했으며 JSON 가져오기로 복원할 수 있습니다. 이름을 붙여 저장한 사용자 프리셋은 유지됩니다.

모바일은 별도 카메라와 텍스트 배치를 사용하고, 좁은 세로 화면에서는 카메라 거리를 확보합니다. 390px 모바일과 데스크톱에서 로그인·장면 보기, 우측 패널 열기/닫기, 유리 반구 개수 변경과 가로 넘침을 확인했습니다. PNG 내보내기는 3D 장면 전용이며 HTML 문구와 패널은 포함하지 않습니다.
