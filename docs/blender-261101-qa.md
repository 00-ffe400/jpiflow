# 261101.blend 원본 모델 점검

- 원본: 261101.blend, 72프레임, Cycles / Filmic / Medium Contrast, 2800 × 3840.
- 원본 파일을 저장하지 않고 Blender 5.2 백그라운드에서 구조 확인과 700 × 960 / 32샘플 비교 렌더를 수행했다.
- 실제 표시 모델은 Sphere와 Cube 두 개다. Cube는 원형 구멍이 있는 판이며 Array가 6개다. 별도 링 모델은 없다. 숨겨진 wireframe과 배경 모델은 GLB에 넣지 않았다.
- 원본 판 한 장 / 구 / 카메라를 GLB로 추출했다. 원본 절차적 미세 질감은 1024px 노멀, 원본 배경과 반사는 1024 × 512 HDR로 추출했다. 파일 크기는 GLB 약 91KiB, 노멀 약 170KiB, HDR 약 432KiB다.

`node tools/check-blender-model.mjs` 통과.

- 판 중심의 레이캐스트는 통과하고 가장자리에서는 교차하여, 원형 구멍이 실제 지오메트리에 존재함을 확인.
- 원본 메시 위치의 유한값과 노멀·UV 보존 확인.
- 웹 카메라와 원본 GLB 카메라 위치·시야각 오차 0.00001 미만.
- 구 반지름, 6개 배열과 배열 간격 일치.
- JSON 왕복 시 카메라 소수 정밀도 보존, 이전 비교 프리셋 검증, 잘못된 타입·색상과 범위 검증.
- 노멀맵 해상도와 HDR 형식 확인.
- 수정한 JavaScript 파일 구문 검사 통과.

## 브라우저 확인

- 데스크톱 1440 × 900: 로그인과 오른쪽 패널 유지. 원본 판 개수를 3개, 두께를 0.13u로 바꿨을 때 장면과 슬라이더 값이 연결됨을 확인하고 선택 그룹 초기화로 복원.
- 이전 타일 프리셋으로 전환한 뒤 원본 Blender 프리셋으로 복원. 조명 유형이 바뀌면 실제 조명 객체도 교체.
- 투명 PNG 생성: 761 × 853 이미지 미리보기 로딩 확인. 자동 다운로드 파일 수신은 브라우저의 data URL 접근 제한으로 직접 검사하지 않았다.
- 모바일 390 × 844: 문서 폭 390px, 가로 넘침 없음. 3D 영역 366 × 약 287px, 접히는 우측 패널 폭 366px. 로그인 56px, 계정 링크와 설정 버튼 44px 터치 높이 확인.
- 수동 움직임 줄이기 선택 시 reducedMotion=true와 모션 버튼 비활성화, 해제 시 복원.
- 원본 비율 729 × 1000 장면 전용 보기에서 비교. 최종 새로고침 이후 콘솔 오류·경고 없음. 검토용 뷰포트 크기를 원래 크기로 복원.
- 원본 파일은 42,616,434바이트와 기존 수정 시각을 유지했다.

## 표현 범위

형상과 배치는 원본이다. Cycles의 복합 translucent / transparent / glass / glossy 재질은 WebGL 물리 재질로 근사한다. 유리판 겹침을 보이게 하기 위해 넓은 면과 절단면의 불투명도를 분리하며, 양면 렌더와 별도 깊이 패스로 유리에도 초점 흐림을 적용한다. 실시간 경로 추적이나 다중 내부 굴절, 카우스틱을 동일하게 재현하는 구현은 아니다. 기본은 정지 상태로 비교하고, 모션 재생 시 구만 은은하게 부유한다.

로컬 검토와 GitHub 저장만 진행하며 main 병합과 공개 배포는 하지 않는다. 원본 .blend는 저장소에 포함하지 않는다.
