## 표현 범위

형상과 배치는 원본이다. Cycles의 복합 translucent / transparent / glass / glossy 재질은 WebGL 물리 재질로 근사한다. 초기 버전의 면별 알파 혼합은 새 기본값에서 제거했다. 기본값은 불투명도 1·물리 투과율 1이며, 뒤→앞 순서로 렌더한 유리를 다음 유리의 굴절 입력으로 사용한다. 단면의 광학 경로와 내부 흡수로 깊이를 표현하고 양면 렌더와 별도 깊이 패스로 유리에도 초점 흐림을 적용한다. 실시간 경로 추적이나 다중 내부 굴절, 카우스틱을 동일하게 재현하는 구현은 아니다. 후속 요청에 따라 기본 모션을 첫 판 구멍에 들어갔다 나오는 6초 자동 왕복으로 변경했다. 유리판은 움직이지 않으며 기존 수직 부유도 선택할 수 있다.

로컬 검토와 GitHub 저장만 진행하며 main 병합과 공개 배포는 하지 않는다. 원본 .blend는 저장소에 포함하지 않는다.

## 유리 사이 왕복 모션 후속 검증

- 원본 첫 판의 법선 방향으로 최대 0.62u 이동한다. 시작 구의 중심이 실제 구멍의 중심선과 일치함을 확인했다.
- 최대 진입 시 중심이 첫 판을 살짝 지나지만 구의 끝이 두 번째 판에 닿지 않는다. 원본 구멍에 구가 통과할 여유도 레이캐스트로 확인했다.
- 6초 주기: 밖에서 대기 → 부드럽게 진입 → 안에서 대기 → 복귀 → 밖에서 대기. 구간 연결부 속도와 가속도가 0인 smootherstep 사용.
- 왕복 대칭, 끝점, 주기 반복, 다음 판과의 여유, 모션만 바꾸는 마이그레이션의 카메라·재질·위치 보존을 자동 검증했다.
- 브라우저의 진행률 0 / 0.5에서 밖 / 안 위치를 확인하고 자동 재생으로 복원한다. 깊이·주기·속도·그룹 정지와 움직임 줄이기 지원.

## 구 메시와 초점 선명도 후속 수정

- 구는 원본 반지름과 위치를 유지한 128 × 96 분할 구로 재생성한다. 형태·배열에서 분할 수를 조절하거나 원본 메시로 비교할 수 있다.
- 구를 따라 이동하는 초점의 앞뒤 0.7u는 흐리지 않는다. 주변 유리는 선명 영역 밖 1.25u에 걸쳐 최대 3px로만 흐려진다.
- 메시 정점 수가 원본보다 충분히 증가했는지, 반지름 보존, 선명 범위가 구 전체를 포함하는지 자동 검증했다.
- 선명도·메시 전환 시 왕복 모션, 카메라와 재질을 보존하는지 확인했다. 브라우저 진행률 0.5에서 진입한 구와 가까운 구멍의 선명도를 확인했다.

## 원본 유리 질감 방향 후속 수정

- 넓은 면과 절단면의 기본 색은 흰색이다. 원본 IOR 1.5, 낮은 거칠기, 원본 HDR과 베이크한 미세 노멀을 사용한다.
- 넓은 면은 실제 얇은 판의 광학 두께, 짙은 절단면은 긴 내부 광학 경로와 Beer–Lambert 흡수로 표현한다. 메시에 불투명한 회색 띠를 칠하는 기본값을 제거했다.
- 겹친 유리를 한 번에 그리던 방식에서 한 장씩 뒤→앞으로 합성하는 방식으로 바꿨다. 이전 유리까지 담긴 선형 HDR 이미지를 다음 유리의 굴절 입력으로 사용한다. 불투명 물체는 색을 다시 칠하지 않고 깊이만 유지하여 구 앞뒤 관계를 보존한다.
- 구멍 내부의 방사형 노멀을 연결했다. 원본 형상과 UV는 바꾸지 않는다.
- 핑퐁 렌더 타깃을 재사용하며 모바일 낮은 품질에서는 MSAA를 끈다. 형태·배열에서 기본 렌더 방식으로도 전환할 수 있다.
- `node tools/check-glass-composite.mjs`: 뒤→앞 순서, 활성 출력 텍스처 피드백 방지, 불투명 깊이·색 처리, 출력 타깃과 중단 시 상태 복원 통과.
- 재질만 새 기본값으로 전환할 때 카메라·구 메시·초점·왕복 모션을 보존하는지 자동 검증했다. 이전 장면은 별도 백업 키로 유지한다.

- 새 겹침 굴절 렌더에서도 투명 PNG 미리보기 443 × 872 로딩을 확인했다. 최종 브라우저 콘솔에 새 오류·경고가 없었다. 자동 왕복으로 복원하고 조절 중인 카메라 구도는 보존했다.
